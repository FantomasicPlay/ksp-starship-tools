# KSP Starship Tools

Два инструмента для полётов Starship / Super Heavy в Kerbal Space Program:
телеметрийный оверлей поверх игры и доработанные kOS-скрипты управления
ускорителем, кораблём и башней.

## KspOverlay

Оверлей в стиле трансляций SpaceX: скорость, высота, шкала двигателей, шкала
топлива и лента вех полёта (Liftoff → Max Q → Stage Sep → SECO → посадка
ускорителя → посадка корабля).

Приложение на WPF с окном без рамки поверх игры; вся отрисовка — HTML/SVG
внутри WebView2. Данные читаются из `telemetry.json` и `telemetry_ship.json`,
которые пишут kOS-скрипты примерно 10 раз в секунду.

Как это устроено:

- `MainWindow.xaml.cs` — окно, прозрачность, чтение файлов телеметрии, отдача
  их в страницу;
- `ui/index.html` — вся визуальная часть и логика вех;
- `overlay.config.json` — путь к папке со скриптами KSP.

Вехи имеют ровно два состояния. Пока аппарат не прислал факт события, веха не
подсвечивается, а её метка не может оказаться левее текущей отметки времени —
только так «пройдено» не загорается раньше самого события. Положение метки до
факта берётся из живого предсказания аппарата, а если его нет — из оценки по
тяговооружённости на отрыве.

### Установка

Скачать архив из [Releases](../../releases), распаковать, запустить
`KspOverlay.exe`. В `overlay.config.json` указать папку `Ships/Script` своей
установки KSP.

Сборка требует .NET 8 SDK:

```bash
dotnet publish KspOverlay.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Файлы из `ui/` копируются в папку сборки. После правки `ui/index.html`
приложение нужно пересобрать либо скопировать файл в `bin/.../ui/` вручную —
оверлей раздаёт страницу из папки сборки, а не из исходников.

## scripts

kOS-скрипты полёта. Это доработанные версии скриптов из мода Starship Launch
Expansion — оригинальная логика подъёма, разворота и посадки принадлежит
авторам мода, здесь лежат правки поверх неё.

- `booster.ks` — Super Heavy: подъём, буст-бэк, планирование, посадочный ожог,
  ловля в руки Mechazilla;
- `starship.ks` — Starship: выведение, орбита, вход в атмосферу, посадка;
- `tower.ks` — башня: руки, толкатели, стабилизаторы, приём команд с аппаратов.

Основные доработки относительно оригинала:

- **Тяга Raptor измеряется в полёте**, а не берётся константой. Константа была
  завышена примерно на 15 %, из-за чего высота включения посадочного ожога
  считалась неверно и касание получалось на 30 м/с.
- **Разворот в позу планирования** ведётся одной замкнутой целью вместо двух
  открытых крутилок вокруг замороженной оси. Прежняя опора «верха» вырождалась
  в момент, когда крыша аппарата приходила к зениту, и крен получал
  произвольную команду.
- **Ловля в руки**: угол поворота башни считается по проекции вдоль оси
  аппарата (с учётом наклона) и фиксируется у земли с упреждением по тренду;
  створ рук держит горловину под ошибку наведения и смыкается по команде
  захвата.
- **Телеметрия и лог полёта**: `telemetry*.json` для оверлея и подробный CSV со
  всеми величинами наведения — по нему разбираются промахи и удары.

Скрипты кладутся в `Ships/Script` вашей установки KSP. Скомпилированные `.ksm`
в репозиторий не входят: kOS пересобирает их сам.

## Требования

- Windows, .NET 8 (для self-contained сборки не нужен)
- WebView2 Runtime (в Windows 11 уже есть)
- Kerbal Space Program с kOS и Starship Launch Expansion
